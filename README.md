# Gravity
Physics Based Game using Phaser - CMPM 120  
Play on itch.io!  

Levels
----------------------
Gravity features 3 different levels:

- Level 1: Spikes
- Level 2: Triggers
- Level 3: Inertia

Upon completion of a level, the player is given a summary/evaluation of their performance as well as a sneak peak into the title of the next level.  

Gameplay
----------------------
Gravity features Phaser's Arcade physics and utilizes manipulating gravity as its core mechanic. It features discrete inputs in the form of clicking WASD to shift gravity as well as continuous inputs such as holding down the spacebar to slow down time.  

Since the player is not able to directly move any object or character in the game, they must rely on gravity and momentum to achieve their goals. Dynamic objects are flung around by the gravity swaps and collide with other static objects such as floor objects or other dynamic objects.
